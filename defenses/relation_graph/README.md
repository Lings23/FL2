# 层间关系残差图防御

`relation_graph` 是 FL2 中可独立选择的 FedAvg 防御。服务端使用模型参数布局、分类器角色、稳定客户端身份和实际上传计算边，图状态保存在防御对象内。

在现有实验配置中选择该方法。

```yaml
strategy:
  name: fedavg
security:
  defense:
    enabled: true
    type: relation_graph
    custom_params:
      settings:
        history_rounds: 12
        min_reference_rounds: 3
        attenuation: 0.9
```

`get_defense` 从注册表加载 `RelationGraphDefense`。Flower 策略提供分类头角色及可训练参数索引。
默认注册身份为 `0` 到 `num_clients-1`，可通过 `custom_params.principal_map` 提供一一对应的稳定身份映射。
模型需要同时包含分类器与其他可训练参数。

## 每轮计算

1. 计算上传与本轮广播的差值。分别在骨干参数和分类头参数上计算客户端对的余弦相似度。每个角色组对具有非零更新的共同张量求平均。只有两个角色组都具备观测时才记录该边。
2. 按骨干相似度对过去窗口中的边分箱。用对应箱内任务相似度的中位数和 MAD 建立参照，再加入限幅的同一客户端对历史偏移。当前边相对参照的正残差构成异常协同候选。
3. 按真实全局轮次衰减共同观测。保留当前超过阈值、近期重复出现且具有足够累计支持的边。候选连通子图还须满足内部密度及外部边证据要求。外部边需要已取得参照且残差未超过阈值。
4. 输出 `no_anomaly_evidence`、`insufficient_evidence` 或 `anomalous_structure`。前两种状态使用样本加权。确认子图后，根据内部边强度连续下调成员权重。

令样本份额为 \(p_i=n_i/\sum_j n_j\)，图风险为 \(r_i\in[0,1]\)，降权系数为 \(\lambda\)。客户端权重为 \(w_i=p_i(1-\lambda r_i)\)，转给广播模型的权重为 \(\sum_i p_i\lambda r_i\)。普通客户端维持原样本份额，整数缓冲区按仓库 FedAvg 的取整方式处理。

## 方向 A：天花板校准与稠密核确认

默认 `Settings` 字段和值保持不变，以下规则在 `graph.py` 内部生效，已有配置与
checkpoint 仍可加载。

1. **抗污染的箱内基准**：历史同时维护全局任务池和非负任务池。若某箱中位数低于
   全局中位数且全局中位数为正，则用全局正基线锚定该箱；同箱正负混合时只用非负边
   估计中心与 MAD；高相似箱的正样本占比低于 20% 且高于全局正中心时，按占比向全局
   正基线平滑，避免 4 客户端小集团把自己的高相似箱标定成“正常”。
2. **余弦剩余空间**：余弦相似度接近 +1 时方差收缩，`pair_shift` 的历史观测只保留
   未被判为异常的边（`score is None` 或 `score <= edge_z_threshold`），最大偏移按
   `1 - max(0, center)^2` 缩放；残差 Z-score 的分母乘以
   `max(0.15, 1 - max(0, center)^2)`。因此 0.84 附近的中心、0.99 的集团边仍可超过
   3.0，而不会因为 0.15 的固定偏移上限被数学封顶。
3. **稠密核剥离**：连通分量在确认前先迭代剥离最低度节点，直到密度达标或只剩 3
   个节点；确认集团要求 `len(component) >= 3`，2 节点单边只算边级异常，不构成集团。
   `links` 与 `incident` 度数严格限制在分量内部，桥接节点不会分摊集团风险。
4. **有符号边界对比**：确认集团还要求内部任务相似度中位数比边界高至少 0.25，
   避免“内部 0.78、边界 0.85”的伪集团。

离线回放见 `experiments/relation_graph_direction_a_replay.py`；`Settings` 的默认值
不变，因此该回放与正式运行使用同一组参数。

## 状态和验证

`diagnostics()` 返回本轮状态、边参照与残差、有效观测质量、确认子图和实际聚合权重。`state_dict()` 与 `load_state_dict()` 保存及恢复轮末窗口、模型布局和配置。历史按全局轮次过期，缺席期间保持缺失观测。异常上传在状态提交前报错。

现有参照采用滞后窗口内的经验中位数与 MAD。箱内需要至少三轮、六对不同客户端的观测才能建立默认参照。冷启动、样本稀疏和全图共同漂移可能落入证据不足。风险表示结构证据强度。长期受污染的分箱、孤立攻击者和连接多个群体的异常桥边是当前原型的验证重点。默认阈值用于固定样例，正式实验需用独立轨迹校准。

```powershell
.venv\Scripts\python.exe -m pytest tests/test_relation_graph.py -q
```
