七、指标、配对和统计要求

每阶段同时报告active/final ACC；targeted attack以ASR为主，并报告峰值/尾部；
恶意/良性权重、带符号方向贡献、anchor贡献、zero/effective mass、良性误伤、
检测延迟、首次机制分叉和聚合耗时。旧impact_norm只表示非负幅度，不能当成净攻击方向。
不可用指标标为缺失，不填0，不从现有范数日志虚构向量信息。

攻击标签和恶意身份只用于离线诊断，不进入防御决策；阈值不能用测试攻击结果泄漏校准。
