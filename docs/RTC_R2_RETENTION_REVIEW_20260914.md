# R2研究保留结论修正

日期：2026-09-14。依据：用户指出R2已有良好防御效果且接近效用门，直接舍弃不妥。

## 修正后的结论

R2应标记为“未通过本次预登记效用验收，但保留为有前景的安全机制候选，待进一步验证”。
此前将单seed验收失败进一步解释为结束该机制的后续验证，决策过于绝对，现予纠正。
本说明修正研究去留判断，不追改原实验协议、阈值、decision.json或独立review.json。
原candidate_accepted=false/candidate_rejected=true仍准确表示该批次未通过全部原定验收门。

## 支持保留的真实证据

以analysis/rtc_r2_review/review.json及logs/rtc_r2_raw_norm/analysis/decision.json为准：

- Gaussian seed42的135/135条攻击更新被识别并实际置零，恶意权重从每轮17.1728%降至0。
- 活跃期良性标记0/365；clean标记0/600，clean准确率、客户端日志与聚合sketch轨迹一致。
- 平均ACC从83.9470%升至84.1034%，提高0.1564个百分点；最终从87.19%升至87.60%，提高0.41个百分点。
- 平均ACC距原+0.2个百分点门还差0.0436个百分点；该门是预登记的工程效用目标，并非证明机制无价值的自然边界。
- 六项完成性、22项质量门、严格配对、预算与独立复核均通过。没有证据显示本批次失败来自误伤或检测遗漏。

因此，“这一批未通过预登记筛选”有依据；“幅度机制无效或应永久舍弃”没有被这些数据证明。
单seed也不能证明该小差距稳定存在、差距纯属随机波动、机制已经泛化有效，或真实误伤概率为零。
R2仍低于同seed RFA的平均ACC，且zero mass从4.8156%增至13.23%；收益与成本都应继续报告。

## 后续研究安排

1. 保留当前固定R2实现、clean来源阈值3、原结果和源码归档；不在seed42上调阈值或反复寻找通过结果。
2. 恢复R2固定多seed复核为计划待办。新实验前一次性预登记seed集合、主要终点、样本量、汇总与停止规则；
   不以“某个新seed通过”为停止条件，不把轮次或客户端记录当独立seed扩大统计样本量。
3. 复核同时考察恶意权重抑制、良性误伤、clean/攻击下效用、zero/anchor质量及预算；报告配对差值与不确定性。
   若将它定位为安全组件并改用“防御收益明确且效用不劣”的研究目标，应在新结果出现前登记，
   并明确这是新研究问题，不能据此把旧+0.2个百分点门改判为通过。
4. Random-v2及其他攻击的验证仍属于总体目标。范数匹配攻击可能不触发R2，不能把“不标记”等同安全。
   R1c与R2是否可以互补，应在单独复核后作为组合候选另行验证，不能直接推定组合有效。

已有R3观测批次及冻结合同保持可执行，R2不再从后续研究计划中排除。
本次只完成结论与计划修正，没有启动训练、创建新实验批次或修改任何已冻结脚本和参数。
当前人工实验交接仍为R3-observe；总体目标仍未完成。
